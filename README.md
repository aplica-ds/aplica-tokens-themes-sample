# aplica-tokens-themes-sample

Sample **Aplica Design** themes (v1.0): pre-built JSON you can import into **Tokens Studio** as a model. The `dist/` directory is the versioned token distribution for this example repo.

- **Product:** [aplica.me](https://aplica.me)
- **Theme engine:** [@aplica/aplica-theme-engine](https://www.npmjs.com/package/@aplica/aplica-theme-engine)

**Documentation in this repository is written in English.**
